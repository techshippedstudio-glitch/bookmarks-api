## Contradictions found

1. **spec.md disagrees with itself on paging, and the old line is not marked as replaced.** The duplicate-save answer at line 15 carries a "Superseded" note. The paging answer at line 18 has no such note, but line 23 overrides it.
   - spec.md:18 "Return pages: 20 per page by default, up to 100 per page, using a limit and an offset, plus the total count."
   - spec.md:23 "Each page returns an opaque next-page token ... The offset option is removed, and a request that still sends it gets a validation error"
   - research.md:99 also lists offset paging as "the original decision; violates VI".

2. **The old duplicate rule is still in spec.md.** It is marked as replaced, so this is not a live conflict, but it is still there to be read:
   - spec.md:15 "Reject it with a conflict error that includes the existing bookmark's identifier" (with the note "Superseded on 2026-10-24")
   - spec.md:27 "returned unchanged with 200 OK instead of a conflict error"
   - research.md:61-62 keeps the history: "returned as 409 `duplicate_url` with `details.existing_id`."

3. **Trailing slash: "slash" or "slashes".** The spec uses the singular. The design docs remove every trailing slash. For a link like `/docs//`, the spec does not say which applies.
   - spec.md:16 "trailing slash on the path removed"
   - data-model.md:48 "Remove trailing slashes from the path."
   - research.md:68-69 "strip one or more trailing slashes from the path"

4. **tasks.md: its description of task status does not match the checkboxes.**
   - tasks.md:20-21 "tasks the revision changes are open (`[ ]`) and marked 'changed 2026-10-24'"
   - tasks.md:50, 71, 77, 78, 150, 151 are each marked "(changed 2026-10-24)" yet all are checked `[X]`, as is tasks.md:167 "Open work for the 2026-10-24 change". So the file does not say clearly whether that work is done.

5. **The spec's status does not match how the other documents treat it.** It is labelled draft, but plan.md and tasks.md were rebuilt from it.
   - spec.md:7 "**Status**: Draft"
   - plan.md:3 "revised 2026-10-24: duplicate saves | **Spec**: [spec.md](spec.md)"

6. **The checklist is out of date.** It says the edge cases are still open questions, but the spec now answers them.
   - checklists/requirements.md:35-37 "The Edge Cases section lists open behavior questions (duplicate handling, link equivalence, ...)... they are the focus for `/speckit-clarify`"
   - spec.md:129-147 states settled answers for each of those edge cases.
