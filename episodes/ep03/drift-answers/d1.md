## Contradictions found

1. **What a duplicate save returns: 200 vs 409.**
   - spec.md and tasks.md say 200: `spec.md:15` "200 OK (no longer a conflict error)", `spec.md:154-157`, `spec.md:46`, `tasks.md:57` "saving an equivalent link returns 200 with the existing bookmark unchanged", `tasks.md:71`.
   - openapi.yaml, quickstart.md and research.md say 409: `contracts/openapi.yaml:25-26` (409 with `existing_id`, no 200 listed), `contracts/openapi.yaml:129` (`duplicate_url` in the error-code enum), `quickstart.md:39` "409 `duplicate_url`", `research.md:39-40` "raise a duplicate error carrying its id", `research.md:87` "`duplicate_url` (409, `details.existing_id`)".
   - Unlike the paging change, none of the convergence tasks in tasks.md (T029 to T036) fixes the contract, quickstart or research for this.

2. **Paging: offset vs cursor (the later text says it replaces the earlier).**
   - Offset: `spec.md:18` "using a limit and an offset, plus the total count", `tasks.md:81-82` "returns saved bookmarks newest first with `total`, `limit` and `offset`", `tasks.md:93` "`BookmarkPage {items, total, limit, offset}`", `tasks.md:95` "`offset` (0 or greater, default 0)".
   - Cursor: `spec.md:23` "The offset option is removed", `tasks.md:84-85` "T017-T020 built offset paging, which Principle VI now forbids ... kept as history", `tasks.md:206-208` (T032 to T034), `research.md:80` "limit/offset (the original decision; violates VI)".

3. **How many dependencies.**
   - `plan.md:53` "Six runtime/test dependencies, each justified in research.md".
   - The table at `research.md:107-113` lists seven: fastapi, uvicorn, sqlalchemy, alembic, psycopg[binary], pytest, httpx2.

4. **Trailing slashes: one or several.**
   - `spec.md:16` "trailing slash on the path removed" and `spec.md:129` "a trailing slash on the path".
   - `research.md:49` "strip one or more trailing slashes from the path" and `data-model.md:48` "Remove trailing slashes from the path".
   - The meaning is the same for a single slash. The spec just doesn't say what happens to several.

5. **Which Python versions are tested.**
   - `plan.md:21` "tested on 3.12 and 3.13".
   - `tasks.md:202` (T031) "Run the full test suite on Python 3.11 and 3.12".

6. **Whether edge cases are still open.**
   - `checklists/requirements.md:35-37` "The Edge Cases section lists open behavior questions (duplicate handling, link equivalence ...)".
   - `spec.md:125-140` gives settled answers to all of them, so the checklist note is out of date.

7. **Which errors use the error envelope.**
   - `plan.md:52` "One envelope ... for validation (422) and not found (404)" leaves out 409.
   - `research.md:87` and `contracts/openapi.yaml:129` include `duplicate_url` (409) in the same envelope. This matters only if duplicates really return 409, which is contradiction 1.
