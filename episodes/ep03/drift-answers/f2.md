## Contradictions and inconsistencies between files

None of these conflict with the current 200 / no-change / cursor-paging behavior.

1. **Trailing slash: one or several?** The spec uses the singular. research.md says one or more slashes are stripped, and data-model.md uses the plural.
   - `spec.md:16` "trailing slash on the path removed"
   - `research.md:55` "strip one or more trailing slashes from the path"
   - `data-model.md:48` "Remove trailing slashes from the path."

   The material does not say whether `https://example.com/docs//` counts as the same link as `/docs`.

2. **Offset paging tasks are still in tasks.md.** tasks.md still lists finished tasks that built offset paging, while every other file forbids offset. tasks.md marks them as history itself.
   - `tasks.md:20` (T020) "`limit` (1 to 100, default 20) and `offset` (0 or greater, default 0) query parameters"
   - `tasks.md:98` (T018) "`BookmarkPage {items: list[Bookmark], total, limit, offset}`"
   - The other side: `openapi.yaml:115` "required: [items, total, limit, next_cursor]" and `data-model.md:36` "`offset` | Not accepted (Constitution VI); sending it returns 422"
   - The note marking them as history: `tasks.md:89-90` "T017-T020 built offset paging, which Principle VI now forbids ... these tasks are kept as history."

3. **The old 409 duplicate rule is still in the text, but struck through or marked replaced.**
